# Knot Web — 프론트엔드

GDGoC 부원끼리 공모전·프로젝트 팀원을 찾는 서비스 **knot**(Tied by trust)의 웹 프론트엔드입니다.
요구사항 정의서와 Figma `knot 디자인 – 전체화면`을 바탕으로, 휴대폰에서 앱처럼 쓰는 PWA 형태로 구현했습니다.

배포 주소: https://knot-web-ten.vercel.app

`src/data.js`의 데이터는 모두 가짜(예시) 데이터이며 실제 동아리원의 개인정보를 포함하지 않습니다.
백엔드 연결 전이라 화면에서 바꾼 내용은 브라우저(localStorage)에만 저장됩니다.

## 실행

```bash
# 1. 설치 (처음 한 번만)
npm install

# 2. 실행 → http://localhost:5173
npm run dev
```

테스트용 가입 코드: `GDGOC2026` (대소문자 구분 안 함)

### 다른 실행 방법

```bash
npm run build        # 배포용으로 묶기 (dist/ 폴더에 생성)
npm run preview      # 묶은 결과를 내 컴퓨터에서 확인
npx vercel --prod    # 배포 주소에 반영
```

### 예시 데이터 처음 상태로 되돌리기

```js
// 브라우저 F12 → Console에 입력 후 새로고침
localStorage.removeItem("gdgoc-match-v1")
```

## 주요 정책

**역할 · 모집 인원**
- 역할은 `기획 · 디자인 · FE · BE` 4개만 사용
- 모집 인원은 역할별로 정하고, 팀장도 자기 역할을 하나 골라 인원에 포함 (게시하면 1/전체로 시작)
  - 예: 팀장 FE + FE 1명 · 디자인 1명 모집 → FE 1/2, 디자인 0/1, 팀 1/3
- 모든 역할이 차거나 진행 종료일이 지나면 자동 마감. 자리가 다 찬 역할의 대기 요청은 자동으로 '모집 마감' 처리
- 수정할 때 확정 팀원이 있는 역할은 뺄 수 없고, 확정 인원보다 적게 줄일 수 없음
- 필수 · 우대 기술은 역할마다 따로 정하고, 둘 다 선택 입력 (팀장이 원하는 기술이 있을 때만). 카드 · 검색 · 추천에는 모든 역할의 기술을 합쳐서 씀

**지원 · 제안 · 응답**
- 지원·제안·수락·거절·마감·삭제처럼 되돌리기 어려운 동작은 확인 창을 한 번 더 띄움
- 한 줄 메시지는 선택 (최대 50자)
- 수락·거절 후에도 모집 마감 전까지 취소 가능 → 다시 '대기'로 돌아감
- 마지막 자리를 수락할 때 "마감되면 취소할 수 없어요"를 미리 안내함
- 자동으로 정리된 요청은 직접 거절과 구분해 '모집 마감'으로 표시함
- 모집이 끝난 뒤에는 팀장이 확정 팀원을 내보낼 수 있음 → 그 역할 자리가 비고 모집이 다시 열림, 내역에는 '팀에서 빠짐'

**채팅방**
- 문의용 오픈채팅: 모집글에 항상 공개
- 팀 채팅방: 팀장은 처음부터, 확정 팀원은 모집이 끝난 뒤에 보임

**내역 · 매칭 · 알림**
- 매칭 성사: 모집글 진행 기간이 끝나기 전까지 표시. 아직 매칭 화면을 안 본 새 매칭만 4색 테두리
- 지난 내역: 진행이 끝난 매칭 + 거절된 것, 최근 1년만 표시
- 알림: 최근 30일만 표시. 모두 읽음 / 하나 삭제 / 전체 삭제. 수락이 취소된 매칭 알림은 숨김

**프로필 · 수료**
- 프로젝트 경험은 공개로 설정한 것을 개수 제한 없이 표시
- 수료는 운영진이 지정한 기수로 표시 ("6기 수료", 여러 개면 펼쳐 보기)
- 개인 활동 체크리스트는 본인 확인용 계산기로 사용 (서버 저장 없음, 기준 점수 없이 누적)

**탈퇴**
- 사람 정보를 찾을 수 없으면 모든 화면에서 '탈퇴한 회원'으로 표시
